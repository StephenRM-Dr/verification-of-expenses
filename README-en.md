# Brailer Ledger Backend (Golang)

This is the main backend for the **Brailer Ledger** system, a minimalist financial application that allows managing transactions, generating Excel reports, and sending notifications directly to WhatsApp groups.

## Technologies Used
- **Language:** Go 1.25.0
- **Database:** PostgreSQL (using `github.com/jackc/pgx/v5`)
- **WhatsApp Integration:** `go.mau.fi/whatsmeow` (based on the Signal Protocol)
- **Excel Export:** `github.com/xuri/excelize/v2`

## Prerequisites
1. Install [Go 1.25+](https://go.dev/dl/).
2. Access to a PostgreSQL database (local or cloud-based like Neon DB).
3. (Optional) Linked WhatsApp account to send reports.

## Local Setup and Execution

1. **Clone and download dependencies:**
   ```bash
   go mod download
   ```

2. **Environment Variables (Optional but recommended):**
   You can configure these variables directly in your terminal or system before running:
   - `DATABASE_URL`: Connection string to PostgreSQL. If empty, it will use the default connection to Neon DB.
   - `PORT`: Port for the API server (default: `8080`).

3. **Run the application:**
   ```bash
   go run main.go
   ```
   *Note: The application will start an interactive menu in the terminal if a TTY environment is detected, while simultaneously running an API server in the background on port 8080.*

4. **Build for production:**
   ```bash
   go build -v -o main .
   ./main
   ```

## WhatsApp Integration
Upon startup, the application will attempt to connect to WhatsApp asynchronously. If it's the first time running (and no session database exists), a QR code will be printed in the API console, or it can be fetched via the `/api/whatsapp/status` endpoint to link your device from the WhatsApp app.

## Common Troubleshooting

1. **Error: "Failed to connect to database"**
   - Verify that the `DATABASE_URL` variable is correct. If using Neon DB, make sure to append `sslmode=require`.
   - Check your internet connection or firewall if pointing to an external DB.

2. **WhatsApp fails to send or shows "not connected"**
   - Ensure you have scanned the QR code correctly.
   - If the session appears corrupt, delete the `.db` files generated by whatsmeow (`whatsapp_final_vX.db`) in the project root and restart the app to scan again.

3. **CORS or API errors from the Frontend**
   - Ensure the backend is running on the correct IP. In `main.go`, the CORS middleware is configured to accept all requests (`*`), but verify that no firewall is blocking port `8080`.

4. **Server stops running in the Cloud (Railway/Koyeb)**
   - The `main.go` file includes a loop to prevent premature exits in non-interactive mode. Make sure to properly configure the `PORT` in your cloud platform's environment variables.
